# Team Spirit · 机甲杯算法视觉中期考核

## 评分项与证据

| 评分项 | 分值 | 验收证据 |
|---|---:|---|
| 待激活及已激活识别 | 10 | 实时画面中用 PENDING 和 ACTIVE 标出对应靶位及灯条 |
| 相机调用与实时显示 | 10 | Gazebo 相机话题、画面和变化的仿真时间 |
| 位姿、当前枪管的转角 | 10 | PnP 相机坐标、Rodrigues 旋转向量、重投影误差与几何 Δyaw / Δpitch |
| 固定、随机固定、小、大能量机关 | 40 | 官方记分板四种模式各累计五次有效命中 |

算法档位按中期考核标准计分，A 为 51–70 分，B 为 41–50 分。Gazebo 记分板用于验证命中次数，画面上的比赛分值与中期考核分值各有独立规则。

## 算法

1. 用 CameraInfo 内参与仿真摄像机装配外参，将颜色分割得到的灯条中心投影至当前阵营的靶面。利用已知灯距和五等分角度约束，验证每块板的四个灯位。两条切向灯同时可见为 ACTIVE，四条同时可见为 PENDING。
2. 用四个灯条的像素点和靶面局部三维点做 PnP。局部 X 为径向，局部 Y 为切向，Z 由右手系确定。相机坐标遵循右、下、前。画面同时展示基于已知靶面与相机交线的世界坐标，并从当前枪口方位计算到目标的转角。
3. 将观测极角按 72° 周期展开。靶位切换前后可共享轮盘相位。根据历史拟合静止、匀速、局部二次和正弦变速模型。加入图像时间差和仿真球飞行时间，迭代预测待激活靶的落点。在能量机关持续转动时发送角速度前馈。
4. 根据云台反馈估算当前仿真弹着误差，经过帧时间、目标稳定时间、重投影误差和射次间隔检查后，发送单次仿真控制请求。该节点从图像、相机标定与云台反馈取数据。另一个节点独立读取裁判话题、记录演示和命中次数。

## 运行与验收

Ubuntu 24.04、ROS 2 Jazzy、Gazebo Harmonic。官方仿真源代码以组委会仓库提交 7cb65610682e4e8ed74bf958864138d2b225c704 为基准。已有 Gazebo 与 ROS 2 工作区可复用。配齐官方构建依赖及系统的 `python3-opencv`、`python3-numpy` 后，在团队仓库根目录执行：

~~~bash
ROBOMINI_DISPLAY=true bash scripts/run-midterm.sh /实际路径/robomini_sim
~~~

在无桌面环境中省略 `ROBOMINI_DISPLAY=true`。命令使用官方阶段自动推进，由固定靶开始。成功时生成 `midterm-evidence/gazebo-midterm.mp4` 和 `midterm-evidence/official-results.json`。正式验收以裁判的 `mode_hits` 为准。若四项中某项小于 5，保留 `gazebo.log`、`vision.log` 和结果 JSON 检查卡住的阶段。

由组长上传官方 Gazebo 展示视频、技术文档、代码和队伍 Git 仓库地址。

## 官方仿真实测

2026 年 11 月 23 日在 Ubuntu 24.04（WSL）、ROS 2 Jazzy 和官方 Gazebo 仿真中以蓝方自动模式运行。四阶段首次通关用时 **30.169 仿真秒**，前 20 发均为裁判确认的有效命中。

| 阶段 | 有效命中 | Gazebo 记分 |
|---|---:|---:|
| 固定靶 | 5/5 | 150 |
| 随机固定靶 | 5/5 | 200 |
| 小能量机关 | 5/5 | 250 |
| 大能量机关 | 5/5 | 300 |
| 合计 | 20/20 | 900 |

录像保留了相机画面、识别框、位姿与转角，以及通关时官方记分板的四项计数。首次运行的记录器在关闭录像后，因 ROS 的 `int32` 计数类型导致 JSON 导出失败。验收包里的 `official-results.json` 根据该次裁判日志和物理命中日志重建，并与录像中的记分板核对。现已修复数值转换并通过本地回归验证。

## 离线验证

Windows 上已用该代码通过三项离线测试。120 张合成相机图像覆盖红蓝两侧与不同灯效组合，待激活靶世界坐标最大误差为 0.61 mm，PnP 最大重投影均方根误差为 0.28 px。对含切靶的周期变速序列，提前 180 ms 的相位预测最大误差为 0.0040 rad。以上数据来自合成图像和解析模型。官方命中次数及录像以 Gazebo 实跑为准。

从团队仓库根目录复现离线测试：

```bash
PYTHONPATH=ros2_ws/src/robomini_vision python3 -m unittest discover -s vision -p test_core.py -v
```
