# robomini-team-spirit

Team Spirit 参加 **RoboMini 机甲杯 2027** 的代码仓库。

目前是空的，后面会一步步往里加。

## 以后放东西的约定

用到哪个建哪个，不用一次建全：

| 文件夹 | 放什么 |
|---|---|
| `firmware/` | 单片机程序（电控） |
| `vision/` | 视觉算法（算法） |
| `ros2_ws/` | 机器人程序（算法） |
| `hardware/` | 电路板文件（电控） |
| `mechanical/` | 图纸索引（图纸本身放网盘） |
| `docs/` | 规则、接口、联调记录 |

**大文件不进仓库**：三维模型、视频、安装包请放网盘。
